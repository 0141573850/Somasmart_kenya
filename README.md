# SomaSmart Kenya

Version 1 of the SomaSmart Kenya Flutter app.

## Included
- Home
- Subjects
- Notes
- Quizzes
- Profile
- Bottom navigation
- Sample university subjects and quiz

## Run
1. Install Flutter.
2. Open this folder in VS Code or Android Studio.
3. Run:
   flutter pub get
   flutter run

## Build APK
flutter build apk --release

The release APK will normally be found at:
build/app/outputs/flutter-apk/app-release.apk
